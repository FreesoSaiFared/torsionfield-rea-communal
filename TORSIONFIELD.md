## Public task proposals

Open GitHub **Issues → New issue → Torsionfield Community Investigation** to propose a legal, public research or reverse-engineering task. The issue is visible to everyone; execution requires an opted-in contributor with the right tools. The live compute queue remains local until a moderated authenticated public gateway is deployed.
